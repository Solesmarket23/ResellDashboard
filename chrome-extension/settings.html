StockX Scanner Settings

Profit rule: lowestAsk - highestBid - feeSum must be ≥ minProfit.
ROI rule: profit / allIn must be ≥ minRoiPct, where allIn = (highestBid+1) + feeSum.
Avg30d cushion rule: require allIn ≤ avg30d × (1 - cushion). Example: cushion 15% ⇒ allIn ≤ avg30d × 0.85.
Xpress deals rule: require lowestAsk ≤ avg30d × (1 - minDiscount). Uses Seller View and includes all sales rows.
Best-effort: uses product release date if StockX exposes it (Next.js data / “Release Date” section).
Example: 69 excludes any size where Lowest Ask is $69 or less (applies to both bid and xpress modes).
Case-insensitive substring match against the full product URL. Best for exact products (slug) and edge cases.
Case-insensitive substring match against the product page title (<h1>). Best for broad rules.
Category filtering uses text heuristics from the listing card; if a card doesn’t expose its category text, it may still pass.
